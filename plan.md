
# 10X Shop — Development Plan

## Project Goal

Build a responsive online shopping application using React,
TypeScript, Tailwind CSS v4 and DummyJSON API.

## CORE Scope

- React + TypeScript + Vite setup
- Strict TypeScript configuration
- React Router navigation
- Local authentication simulation
- Product catalog and product details
- Shared shopping cart
- Checkout form and local order confirmation
- Responsive layout
- Loading, error and empty states

## FULL Scope

- Formik and Yup validation
- Search with debounce
- Category filtering
- Sorting and pagination
- URL query state
- Product reviews and related products
- Promo code support
- Orders and profile pages
- Dark/Light theme
- Shared toast notifications
- Skeleton loading and retry
- Lazy loading and performance optimization
- Advanced TypeScript patterns and reusable hooks

## BONUS Scope

- Wishlist
- Infinite scrolling
- Price range filter
- Grid/List view
- Extended theme customization
- Custom Tailwind utilities and variants
- Advanced responsive states

## Technology Stack

- React
- React DOM
- TypeScript
- Vite
- React Router DOM
- Tailwind CSS v4
- Formik
- Yup
- DummyJSON API

## Development Phases

1. Project setup and configuration
2. Types, API layer and shared utilities
3. Layout, navigation and authentication
4. Product catalog and product details
5. Cart and checkout
6. FULL features
7. BONUS features
8. Responsive design and accessibility
9. Testing, optimization and QA
10. GitHub documentation and Vercel deployment

## Quality Requirements

- Strict TypeScript with no type errors
- No horizontal overflow on mobile
- Reusable and modular components
- Immutable state updates
- Clear loading, error and empty states
- Working direct route refresh after deployment
- README and final project report
